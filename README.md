# Sony RX10 V — Photo Recipes

A plain-English settings guide for the **Sony RX10 V (DSC-RX10M5)**, built for someone who
wants good photographs without reading a 400-page manual.

**→ [Read it here](https://markcossey.github.io/sony-rx10v-recipes/)**

## What's in it

- **Set up once** — the dozen settings worth changing on day one, then leaving alone
- **Ten recipes** — birds in flight, grandkids indoors, sport, landscapes, sunsets, the moon,
  close-ups, video, and a sensible everyday default
- **Small birds in the distance** — the camera's hardest focusing job, and the four buried
  settings that bear on it
- **Two shutters** — why mechanical and electronic behave like different cameras, and when
  each one is the right choice
- **Reference tables** — aperture as you zoom, hand-holdable shutter speeds, how far ISO goes
- **If the photo came out wrong** — symptom, cause, fix

Every menu name is written exactly as it appears on the camera, checked against Sony's
official Help Guide for this model.

## Editing it

Plain HTML and CSS — no build step, no dependencies.

- `index.html` — all the content
- `style.css` — the styling, light and dark, and a print stylesheet

Edit, commit, push. GitHub Pages redeploys on its own, usually within a minute.

## Notes on the camera

Announced July 2026. 20.1MP 1.0-type stacked Exmor RS sensor, BIONZ XR processor with a
dedicated AI recognition unit, ZEISS Vario-Sonnar T\* 24–600mm equivalent f/2.4–4,
30 fps blackout-free continuous shooting, 4K up to 120p, NP-FZ100 battery, 72mm filter thread.
No built-in flash and no built-in ND filter.
